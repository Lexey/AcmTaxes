# Утилита для расчета расходов по сделкам продажи в ACM Limited

Позволяет импортировать данные о сделках из годовых отчетов ACM Limited в формате xlsx (с листа Рассчитанные операции) в свою "БД" (json со списком сделок).

После по этой базе можно генерировать годовые отчеты, в которых перечисляются все сделки продажи и связанные с ними (по правилу FIFO) сделки покупки.
Для каждой сделки продажи рассчитываются расходы на приобретения проданных активов (комиссии не учитываются, так как они не привязаны к конкретным сделкам).

Полученные данные могут быть использованы для расчета налоговых баз по сделкам для 3-НДФЛ.

Перед запуском нужно в appsettings.json прописать свою лицензию для EPPLus. Для личных нужд вполне подходить персональная некоммерческая лицензия, которая получается простым добавлением своего имени после `NonCommercialPersonal:`.
